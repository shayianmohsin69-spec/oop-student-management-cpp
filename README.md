# OOP Student Management System (C++)

I created this console project to practise object-oriented programming through student records. The Student class uses private data, constructors, a destructor, getters, a setter with marks validation, and a grade calculation. The menu lets users add, view and search students, while file handling keeps records between sessions.

## Requirements
- C++17 compiler such as g++ or MinGW

## Run
```bash
g++ -std=c++17 main.cpp -o students
./students
```
On Windows, run `students.exe` after compiling with MinGW.

## Concepts used
Classes and objects, encapsulation, constructors, getters and setters, vectors, input validation, file handling and conditional logic.
